# 小禾算术

帮助小学生练习算术的纯前端应用。无需登录、无需服务器接口或构建步骤；HTML、CSS、JavaScript 与 SVG 均在本仓库内，无第三方运行时、字体或 CDN 依赖。

## 使用

直接在现代浏览器打开 `index.html` 即可离线使用。建议通过本地服务器打开，以获得更稳定的浏览器存储行为：

```sh
npm run dev
# 打开 http://127.0.0.1:4173
```

需安装 Node.js（测试建议使用 Node.js 20+）。无 npm 依赖，无需 `npm install`。也可以使用 `python3 -m http.server 4173`。

## 已实现

- **课程路径**：六个年级 × 两个学期，按算术专题区分练习范围；独立展示课程与资源依据、版本状态和课堂延伸。
- **视算练习**：批量随机生成10、20、40、60或100题；选择专题、换一组、10～30分钟逐分钟配置。
- **专注计时**：绝对截止时间计时、暂停/继续、提前交卷；到时自动收卷，弹出休息提醒，并在提示音开启且浏览器允许时响铃。
- **打印**：A4练习单，打印内容与当前预览批次一致。打印不启动计时，不记录在线成绩。
- **星星探险**：每次10道选择题、10分钟；首次作答计分、逐题提示、星星奖励与最终结算。
- **错题**：已作答的错误题自动收集；支持单题/批量重练，答对后移出。未填写题在结算中列出，不自动收藏。
- **成长记录**：今日数据、七日题量、最近练习、累计成就与 JSON 导出。
- **恢复练习**：刷新后恢复题目、已填答案与暂停状态；进行中的计时不会因刷新重置。

## 课程范围

以人教版六三学制公开目录和教学计划为线索，聚焦整数、小数、分数、余数、百分数及计算应用。**这是应用内练习路径，不是官方完整教学大纲或逐周计划。**

新版教材与旧版在年级、学期上存在调整。四至六年级下册目前明确标为“衔接建议 · 待核”，其他册次也尚未逐页核对全部官方教材。请按孩子实际课本与已学内容选择专题。几何、统计等仅列延伸提示，尚未提供完整教学。完整调研、取舍和来源见 [docs/curriculum-research.md](docs/curriculum-research.md)，应用内“课程与资源”也可查看。

## 答案与记录

比较大小填 `<`、`>`、`=`；余数填 `3余1`（也接受 `3…1`）；分数填 `1/2`。支持等值分数与有限小数，例如 `2/4`、`0.5` 均可匹配 `1/2`。应用不把近似小数当作精确分数答案。

学习记录使用浏览器 `localStorage`，最多保存100组记录和200道待复习错题，不上传至服务器。不同浏览器、不同本地端口、`file://` 与 `http://` 的数据不共用；清理浏览器数据会删除记录。JSON 导出用于查看和备份，当前没有导入功能。存储禁用或写满时显示提示，仍能在当前页面练习。

设备休眠、浏览器冻结或关闭页面期间无法保证准时发声；恢复页面时按实际截止时间立即收卷。暂停时题目隐藏，暂停时间不计入专注时长。刷新后浏览器可能要求再次用户操作才能播放提示音，弹窗提醒始终保留。

## 开发与验证

```sh
npm test       # Node内置测试：出题、判分、计时、恢复、错题、游戏
npm run check  # JavaScript语法检查
```

| 文件 | 用途 |
| --- | --- |
| `index.html` | 语义化页面与对话框 |
| `src/styles.css` | 响应式布局和打印样式 |
| `src/curriculum.js` | 十二学期、专题范围、来源和版本状态 |
| `src/math.js` | 随机出题、答案解析和选择题干扰项 |
| `src/app.js` | 页面、练习会话、计时和本地存储 |
| `assets/buddy.svg` | 原创小狐狸伙伴 |
| `tests/` | 无依赖自动化测试 |

测试包含跨全部专题的随机样本与独立算式求值校验、输入边界、可控时钟下的超时/暂停/刷新恢复及完整十关流程。界面仍建议在目标设备上检查字号、触控、打印分页和提示音。
