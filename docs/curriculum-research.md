# 课程调研与应用内容规划

调研日期：2026-10-25。范围：人教版六三学制小学数学中的算术与计算应用。

## 应用内的十二学期划分

采用“年级 → 学期 → 算术专题 → 练习/游戏”的层级。每专题用“起步巩固、核心练习、应用提升”标注建议顺序；不声称是教材单元名称的完整复刻。

| 年级 | 上学期专题 | 下学期专题 |
| --- | --- | --- |
| 一 | 5以内加减；10以内加减；两步加减；11～20简单加减；20以内进位加法 | 20以内退位减法；100以内数比较；100以内口算；100以内笔算；加减关系 |
| 二 | 1～6乘法；1～6除法；7～9乘法；表内除法巩固 | 有余数除法；乘除关系；万以内数比较；万以内加减 |
| 三 | 两步混合运算；多位数乘一位数；同分母分数初步计算 | 一位数除法；长方形周长面积；简单小数加减 |
| 四 | 大数比较；多位数乘两位数；加法与乘法模型中的数量关系 | **衔接建议，待核**：两位数除法；四则运算；小数加减 |
| 五 | 小数乘法；小数除法；三角形、梯形面积计算 | **衔接建议，待核**：因数倍数；同/异分母分数加减 |
| 六 | 分数乘法；分数除法；百分数 | **衔接建议，待核**：比与比例；折扣；小学算术综合复习 |

这一划分覆盖计算练习，未覆盖全部课程目标。数的比较仅是数的认识的一种练习；面积题仅训练计算，不能替代面积概念、操作与推导教学。四至六年级下册没有足够的新版核验依据，标为建议路径而不假装是已确认目录。

## 学期教学节奏如何转成练习节奏

本应用的进度是**产品建议**，由家庭根据学校已教内容选择，非统一官方课时计划：

1. 学期前段：已学基础回顾，用起步专题练一组，不要求抢先学。
2. 单元学习期间：选择对应核心专题，先理解算理，再练熟练度。
3. 单元后段：数量关系与生活应用；先看懂问题，再输入答案。
4. 复习阶段：重练错题，结合小游戏检查；不把速度作为唯一评价。

建议默认每组10分钟；家长可选10～30分钟，随时暂停。年级越低，越应按孩子状态安排中途休息。时长与每组题量相互独立，提前答完可以交卷，不必等待计时结束。

## 出题约束

- 一年级加减结果不为负；5/10以内的和受上限约束。11～20专题只生成不进位/不退位；进位与退位分别练习。
- 两步混合运算显式显示括号，先乘除后加减。两步加减包含连加、连减与加减混合，保证中间结果及最终结果在专题范围内。
- 表内乘除限定因数、除数范围；一位数/两位数除法基础专题只出整除题，有余数单独练习，余数小于除数。
- 小数乘除只生成有限小数答案；不涉及循环小数与按要求取近似值。
- 分数使用整数分子分母计算与约分；判分接受等值分数。三年级同分母加法结果不超过1。
- 百分数、折扣、面积题提供明确单位，答案框只填数值。当前不提供竖式书写交互，可打印纸面练习。
- 优先避免同批重复，但小范围题池题量不足时允许重复，并在设置里明确说明。
